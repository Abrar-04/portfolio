## Built with

- **React + TypeScript** for the interface and components
- **Vite** for local development and production builds
- **React Router** for page navigation
- **Custom CSS** for the responsive dark design
- **Lucide React** for icons
- **GitHub Actions + GitHub Pages** for automatic deployment

## Run locally

**Requirements:** Node.js compatible with Vite 6 and npm.

```bash
git clone https://github.com/Abrar-04/portfolio.git
cd portfolio
npm ci
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`).

To test a production build:

```bash
npm run build
npm run preview
```

## Deployment

The site is deployed to **GitHub Pages** through a GitHub Actions workflow. Pushing changes to the `main` branch triggers a fresh installation and production build, then publishes the generated `dist/` output.

```bash
git add .
git commit -m "Update portfolio"
git push origin main
```
